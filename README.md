# Buscador de CEP

Aplicação em Angular para consulta de endereços através de CEP, consumindo a API do [ViaCEP](https://viacep.com.br/).

---

## 🚀 Tecnologias

- **Angular**
- **TypeScript**
- **ViaCEP API**

---

## 💻 Como Executar

### 1. Instalar as dependências
```bash
npm install
```

### 2. Iniciar o servidor de desenvolvimento
```bash
npm start
```

Acesse a aplicação no navegador em: [`http://localhost:4200`](http://localhost:4200)

---

## 🛠️ Outros Comandos

- **Build de produção:**
  ```bash
  npm run build
  ```
- **Executar testes:**
  ```bash
  npm test
  ```
